# Generador de exámenes

Aplicación web estática para crear exámenes, agregar preguntas y realizar una prueba con evaluación automática.

## Características

- Crear un examen con nombre y descripción
- Agregar preguntas con cuatro opciones y respuesta correcta
- Guardar el historial de exámenes en localStorage
- Cargar exámenes guardados
- Iniciar la prueba y mostrar el resultado final

## Uso

1. Abre `index.html` en tu navegador.
2. Crea o edita el examen.
3. Guarda el examen para conservarlo en el navegador.
4. Haz clic en "Comenzar prueba" para responderlo.

## Archivos principales

- `index.html` — lógica y estilos de la aplicación
- `LOGO.PNG.png` — logo de la marca
